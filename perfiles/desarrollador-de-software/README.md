# Perfil: Desarrollador de Software

Esta carpeta conserva la versión anterior del portafolio, antes de reorientarlo hacia automatización, procesamiento de información e inteligencia artificial.

## Contenido

- `src/components/`: componentes anteriores de la home.
- `src/layouts/Layout.astro`: layout anterior.
- `public/CV_Alexander_Polanco_Desarrollo_de_Software.pdf`: CV anterior.

## Perfil activo

La versión activa del portafolio permanece en `src/` y `public/` del proyecto principal. Esta carpeta es un respaldo reutilizable y no participa en la compilación actual.

## Para activar este perfil en el futuro

Copiar los archivos de esta carpeta sobre las rutas equivalentes del proyecto principal y revisar el nombre del CV en los enlaces antes de compilar.
